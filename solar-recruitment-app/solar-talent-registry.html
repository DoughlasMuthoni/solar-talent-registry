Candidate privacy controls

  • Publish a candidate privacy notice before collecting information.
  • Collect only data required for recruitment and licence verification.
  • Separate recruitment consent from optional talent-pool consent.
  • Use role-based access for recruiters, assessors and administrators.
  • Encrypt information in transit and at rest in production.
  • Record access, score changes, verification and status decisions.
  • Define deletion periods for unsuccessful candidates.
  • Provide human review and a way to correct or contest automated results.

Prototype limitation

By default this prototype stores applications only in memory while the page remains open. Use Export to retain a copy. Production deployment requires authentication, a secure database, file storage, backups and audited permissions.
